# Local template apps

Run the apps generated by the Developer Hub templates on your laptop against **Podman Compose** Kafka (+ Postgres for CDC).

## Prerequisites

| Tool | Notes |
| --- | --- |
| **Podman** + **podman-compose** | Infra (`compose.yaml`) |
| **Java 21** + **Maven** | Quarkus trip planner |
| **Go 1.21+** | `brew install go` — Go trip + CDC consumer |

## Quick start

```bash
cd local
podman-compose up -d          # Kafka :9092, Postgres :5432
./materialize.sh              # fills placeholders → apps/
./run-go.sh                   # http://localhost:8082  — same UI/HITL as Quarkus; set MAAS_API_KEY
```

Other terminals:

```bash
./run-quarkus.sh              # http://localhost:8081  — set MAAS_API_KEY in apps/trip-quarkus/.env
./run-cdc.sh                  # http://localhost:8083
./publish-cdc-sample.sh       # sample Debezium JSON → orders-cdc.public.orders
```

## Ports

| App | URL | Kafka |
| --- | --- | --- |
| trip-quarkus | http://localhost:8081 | `flow-in` / `flow-out` |
| trip-go | http://localhost:8082 | `flow-in` / `flow-out` |
| orders-cdc | http://localhost:8083 | `orders-cdc.public.orders` |
| Postgres | localhost:5432 | user/pass/db: `orders` / `backstage` / `orders` |

## What `materialize.sh` does

Copies `software-templates/*/skeleton` into `local/apps/{trip-quarkus,trip-go,orders-cdc}` and replaces `${{values.*}}` with local defaults (`component_id`, `module_path`, ports 8081–8083, etc.). Re-run after template changes.

`local/apps/` is gitignored.

## Quarkus + Red Hat langchain4j BOM

The trip Quarkus app uses **only** the Red Hat `quarkus-langchain4j-bom` (RHBOQ 3.33) — no community langchain4j BOM and no Quarkus Flow. HITL runs through Kafka (`flow-in` / `flow-out`) via `KafkaTripEngine`.

| Gap | Approach |
| --- | --- |
| No `quarkus-langchain4j-skills` in RH | `SkillGuidance` loads `classpath:skills/**/SKILL.md` |
| Agentic orchestration | Manual `TripPlannerService` over `@Agent` beans (parallel vehicle + itinerary, review loop) |

`MAAS_API_KEY`: `run-quarkus.sh` uses `local-dev-placeholder` if unset so Quarkus can start.

## Go note

Template `go.mod` pins `IBM/sarama v1.38.1` for the ACS/RHDA demo; that version still declares the old `Shopify/sarama` module path. The `run-go.sh` / `run-cdc.sh` scripts bump it to `v1.43.3` locally so `go mod tidy` works.

## CDC without Debezium Connect

Compose includes Postgres with logical replication ready, but **no** Debezium Connect in this v1. Use `./publish-cdc-sample.sh` to feed the consumer, or point Debezium at Postgres later.

## Stop infra

```bash
podman-compose down
```
